3ഇലക്ട്രോൺ പൂരണ നിയമങ്ങൾ — ഓഫ്ബൗ തത്വം

ഊർജം കുറഞ്ഞ സബ്‌ഷെല്ലിൽ നിന്ന് ഊർജം കൂടിയ സബ്‌ഷെല്ലിലേക്ക് ക്രമമായി ഇലക്ട്രോണുകൾ നിറയുന്നു.

(n + l) നിയമം

(n+l) വില കൂടി വരുന്ന ക്രമത്തിലാണ് സബ്‌ഷെല്ലുകളുടെ ഊർജം കൂടുന്നത്. (n+l) തുല്യമെങ്കിൽ, ചെറിയ n ന് ഊർജം കുറവ്.

1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d
ശ്രദ്ധിക്കുക: 4s എപ്പോഴും 3d നു മുൻപ് നിറയും; അയോൺ രൂപീകരണത്തിൽ 4s ൽ നിന്നാണ് ആദ്യം ഇലക്ട്രോൺ നഷ്ടപ്പെടുന്നത്.

7പീരിയഡ് & ഗ്രൂപ്പ് നമ്പർ

പീരിയഡ്: സബ്‌ഷെൽ വിന്യാസത്തിലെ ഏറ്റവും ഉയർന്ന ഷെൽ നമ്പർ (n).

ബ്ലോക്ക്ഗ്രൂപ്പ് നമ്പർ കണ്ടെത്തുന്ന വിധം
sബാഹ്യതമ s ലെ e⁻ എണ്ണം = ഗ്രൂപ്പ് നമ്പർ
p(ബാഹ്യതമ s+p ലെ e⁻) + 10 = ഗ്രൂപ്പ് നമ്പർ
d(ബാഹ്യതമ s + ഉള്ളിലെ d ലെ e⁻) = ഗ്രൂപ്പ് നമ്പർ

8ക്രമാവർത്തന പ്രവണത — അയോണീകരണ എൻഥാൽപി

വാതകാവസ്ഥയിലുള്ള ഒറ്റപ്പെട്ട ആറ്റത്തിന്റെ ബാഹ്യതമ ഇലക്ട്രോണിനെ നീക്കം ചെയ്യാൻ വേണ്ട ഏറ്റവും കുറഞ്ഞ ഊർജം.

ഗ്രൂപ്പിൽ മുകളിൽ നിന്ന് താഴേക്ക്പീരിയഡിൽ ഇടത്തുനിന്ന് വലത്തോട്ട്
ഷെല്ലുകൾ കൂടുന്നു → എൻഥാൽപി കുറയുന്നുന്യൂക്ലിയർ ചാർജ് കൂടുന്നു → എൻഥാൽപി കൂടുന്നു

ഏറ്റവും കുറഞ്ഞ അയോണീകരണ എൻഥാൽപി — സീസിയം, ഫ്രാൻസിയം.
